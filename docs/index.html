🚀 How to Use ECLIPSE

Four steps from query to genome download — no installation, no account, no limits.

1

Browse a module

Pick a typing scheme (MLST, Phylogroups, Serotypes, CHTyper) or the Master Table for everything at once.

2

Stack filters

Combine genotype + geography: e.g. ST131 + B2 + United Kingdom + blood + 2010–2020.

3

Export accessions

Click 🧬 Accessions to download a plain-text list of matching genome accession IDs — one per line.

4

Download genomes

Feed the list to NCBI: datasets download genome accession --inputfile list.txt — that's it.

EcoliTyper: Beckley B, Amarh V. EcoliTyper: a species-optimized computational pipeline for comprehensive genotyping and surveillance of Escherichia coli. BMC Bioinformatics. 2026. doi:10.1186/s12859-026-06529-6
