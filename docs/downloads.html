📖 How to use these files

Every file is a gzipped TSV. Decompress and open with pandas, R, or the command line:

gunzip mlst_all.tsv.gz
head -5 mlst_all.tsv

Or read directly from Python without decompressing — pandas handles .gz automatically:

import pandas as pd

mlst = pd.read_csv("mlst_all.tsv.gz", sep="\t")
amr  = pd.read_csv("amr_all.tsv.gz",  sep="\t")
meta = pd.read_csv("eclipse_metadata.tsv.gz", sep="\t")

# Join typing + metadata on accession
df = mlst.merge(meta, on="accession", how="left")
df[df["ST"] == "131"].head()

🧬 Long-format gene tables

amr_all.tsv, vfdb_all.tsv, and plasmid_all.tsv are in long format — one row per (genome, gene) presence. To pivot to a wide presence/absence matrix: 

amr_wide = (amr.assign(present=1)
               .pivot_table(index="accession", columns="gene",
                            values="present", fill_value=0))
