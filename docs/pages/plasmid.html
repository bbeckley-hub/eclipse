About this module

This page lets you retrieve E. coli genomes by plasmid replicons. Pick up to five genes, choose whether samples must match any or all of them, and download the accession list — ready for datasets download genome accession --inputfile list.txt.

Source

ABRicate against the PlasmidFinder database.

How to use it

  1. Click a quick-pick chip, or use the autocomplete search to find any of the 81 genes
  2. Add up to 5 genes — the results table updates instantly
  3. Switch between Match ANY (union) and Match ALL (intersection)
  4. Click 🧬 Accessions to download the accession list as plain text
  5. Or use TSV/CSV/JSON for per-gene presence flags plus metadata

Coverage in this build

  • 1,650 genomes carry at least one plasmid replicons determinant
  • 81 unique replicons
  • 6,483 presence records

Full data download

For the complete presence matrix (long format: accession | gene | num_hits | identities) and the full frequency table, go to the Downloads page. All files are gzipped TSVs.
